SignalF0rge

A Python security analytics and investigation engine that normalizes telemetry, runs 24 native detections, correlates activity across sources, builds entity-centric cases, and exposes evidence through bounded read-only investigation tools.

The investigation layer can run deterministically or use an optional LLM as a planner. The model chooses from a strict read-only allowlist; it cannot execute shell commands, change detections, or override the deterministic severity and evidence. Prompt-injection defenses, bounded graph traversal, and loop protection keep the agent constrained.
